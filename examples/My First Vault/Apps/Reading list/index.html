Reading list

Books to read next, and the ones already finished. Click this paragraph and type: the text around the list is ordinary HTML, so it edits like any other page.

How this page is made

The list is a React app. Its source is in src/, Vite builds it into dist/, and Noteblock shows dist/index.html. Your edits to this text go to index.html. Press ⌘SCtrl+S to save them, and Noteblock rebuilds the page.

All of that is set in the page's .noteblock file: build is the command, entry is the built file, and source is the file your edits go to. Turn on Source in the sidebar to see them.
